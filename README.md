🎮 Tic Tac Toe Web Application

 📖 Overview
The **Tic Tac Toe Web Application** is a fun, interactive, and responsive browser-based game developed using **HTML5, CSS3, and JavaScript**. It recreates the classic **Tic Tac Toe** game, allowing two players to compete by taking turns marking **❌ X** and **⭕ O** on a **3×3 grid**.

The application automatically detects **winning combinations**, identifies **draw situations**, and provides a **Restart Game** option for continuous gameplay.

---

✨ Features
- 🎲 Interactive **3×3** game board
- 👥 Two-player gameplay
- 🏆 Automatic winner detection
- 🤝 Draw detection
- 🔄 Restart game functionality
- 📱 Fully responsive and user-friendly interface
- ⚡ Smooth gameplay experience

---

 🛠️ Technologies Used
- 🌐 HTML5
- 🎨 CSS3
- ⚡ JavaScript (ES6)

---

 🚀 How to Use
1. Open the application in your web browser.
2. ❌ **Player X** starts the game.
3. Players take turns selecting empty cells.
4. 🏆 The game automatically announces the winner or a draw.
5. 🔄 Click the **Restart** button to start a new game.
